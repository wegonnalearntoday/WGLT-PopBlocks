WGLT Pop Blocks - Pack 01 All Categories

What this folder includes:
- index.html = playable Pop Blocks game
- js/config/pack-manifest.js = manifest for all categories
- js/content/all-pack-01.js = Pack 01 content for every current category
- Pack 01 includes:
  - 15 Quiz Boost questions per category
  - 15 Knowledge Pop facts per category

Important:
- Upload the whole folder structure to GitHub, not just index.html
- Keep the js folder next to index.html
- Open index.html as your game entry file

Current category keys match the game's internal category keys:
Black History: red, green, yellow, black, sports, superheroes, entertainers, comedians, musicians, professions, hbcus
Finance: green, yellow, red, blue, retirement, rates, goodbad, ira401k
Civics: blue, red, yellow, green, redlining, governor, mayor, amendments

Pack behavior:
- External category packs feed Quiz Boost and Knowledge Pop
- If you add Pack 02 later, register it in js/config/pack-manifest.js
